Quiénes somos

Notix24 es un canal de noticias en castellano sobre videojuegos, tecnología y motor, en YouTube (@Notix24ES). Esta política describe cómo trata datos la herramienta de escritorio de Notix24, usada solo por el titular del canal, y esta página web.

Qué datos de TikTok se acceden

Cuando el titular inicia sesión con Login Kit de TikTok, la aplicación solicita los alcances user.info.basic y video.upload. En la práctica puede recibir:

  • un identificador básico de perfil (open_id) y el nombre visible de esa cuenta de TikTok;
  • un token de acceso (y, si TikTok lo emite, un token de renovación).

El token se guarda únicamente en el ordenador local del titular. No se envía a un servidor nuestro. Se usa solo para subir borradores de los vídeos cortos del propio canal al buzón de esa misma cuenta de TikTok. La herramienta no publica el contenido de forma automática: el titular lo revisa en la aplicación de TikTok.

No usamos Direct Post y no pedimos el alcance video.publish. La herramienta no está pensada para que la usen terceros.

Qué no hacemos

  • No vendemos ni compartimos esos datos con terceros.
  • No usamos los datos de TikTok para publicidad ni para perfiles de otras personas.
  • Esta web es un sitio estático: no instala cookies de análisis ni recoge datos de los visitantes.

Conservación y supresión

El token permanece en el ordenador del titular mientras la autorización sea válida o hasta que lo borre. Para dejar de conceder acceso y eliminar esos datos:

  1. Revoca el acceso a la aplicación en la configuración de TikTok (por ejemplo, Ajustes y privacidad → Seguridad y acceso a la cuenta → permisos de aplicaciones / aplicaciones autorizadas, según muestre TikTok en ese momento).
  2. Borra el archivo local del token en el ordenador del titular (en la instalación habitual, secrets/tiktok/token.json en la carpeta del programa).

Después de revocar el acceso, el token deja de ser válido ante TikTok.

Esta web

Las páginas de este sitio se alojan en GitHub Pages. No operamos analítica propia sobre quienes las visitan. El alojamiento puede registrar datos técnicos habituales de un servidor web (por ejemplo, en los registros de GitHub); eso lo gestiona GitHub según su propia política.

Contacto

Para ejercer derechos o preguntar sobre esta política, abre una incidencia en: github.com/lerelerele/notix24/issues.

English

Who we are

Notix24 is a Spanish-language news channel covering games, technology and motoring, on YouTube (@Notix24ES). This policy describes how the Notix24 desktop uploader — used only by the channel owner — and this website handle data.

What TikTok data is accessed

When the owner signs in with TikTok Login Kit, the app requests the scopes user.info.basic and video.upload. In practice it may receive:

  • a basic profile identifier (open_id) and that TikTok account’s display name;
  • an access token (and, if TikTok issues one, a refresh token).

The token is stored only on the owner’s local computer. It is not sent to a server we operate. It is used solely to upload drafts of the channel’s own short videos to that same TikTok account’s inbox. The tool does not publish the content automatically: the owner reviews it in the TikTok app.

We do not use Direct Post and we do not request the video.publish scope. The tool is not intended for third-party users.

What we do not do

  • We do not sell or share this data with third parties.
  • We do not use TikTok data for advertising or to profile other people.
  • This website is a static site: it does not set analytics cookies or collect visitor information.

Retention and deletion

The token stays on the owner’s computer while the authorization remains valid or until they delete it. To withdraw access and delete that data:

  1. Revoke the app’s access in TikTok’s settings (for example, Settings and privacy → Security and account access → app permissions / authorized apps, as TikTok labels it at the time).
  2. Delete the local token file on the owner’s computer (in the usual install, secrets/tiktok/token.json in the program folder).

After access is revoked, the token is no longer valid with TikTok.

This website

These pages are hosted on GitHub Pages. We do not run our own analytics on visitors. The host may record ordinary web-server technical data (for example in GitHub’s logs); that is handled by GitHub under its own policy.

Contact

To exercise rights or ask about this policy, open an issue at: github.com/lerelerele/notix24/issues.
